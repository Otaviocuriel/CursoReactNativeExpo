## 📖 Sobre o projeto

O **LinksAPP** é um aplicativo mobile criado durante meus estudos de **React Native e Expo**, com foco em praticar:

* Navegação entre telas;
* Componentização;
* Organização de código;
* Armazenamento local de dados;
* Desenvolvimento mobile utilizando TypeScript.

O aplicativo permite que o usuário salve e organize links em diferentes categorias, facilitando o acesso às informações.

---

## ✨ Funcionalidades

✅ Cadastro de links

✅ Organização por categorias

✅ Armazenamento local com AsyncStorage

✅ Navegação entre telas

✅ Interface moderna e responsiva

## 🚀 Como executar

### Clone o repositório

```bash
git clone https://github.com/Otaviocuriel/CursoReactNativeExpo.git
```

### Entre na pasta

```bash
cd CursoReactNativeExpo/LinksAPP
```

### Instale as dependências

```bash
npm install
```

### Execute o projeto

```bash
npx expo start
```
